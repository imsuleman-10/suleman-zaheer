## 🚀 Technical Highlights

- **Framework:** Next.js 16 (App Router) with React 19
- **Design System:** Custom Dark Glassmorphism, tailored CSS tokens, responsive typography
- **Optimization:** Full SEO, GEO, AEO, and LLMO compliance with pre-rendered static routes (76+ pages)
- **Knowledge Graph:** JSON-LD Schemas (`Person`, `Organization`, `Service`, `FAQPage`, `BreadcrumbList`, `SpeakableSpecification`)
- **Contact Pipeline:** Nodemailer integration with automated instant dual notifications (client confirmation + admin notification)

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/imsuleman-10/suleman-zaheer.git

# Navigate to project
cd suleman-zaheer

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application in the browser.
